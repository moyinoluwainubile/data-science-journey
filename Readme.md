# Data Science Journey

This repository documents my 24-week journey of learning Data Science from the ground up.

It contains my learning exercises, Python scripts, Jupyter notebooks, practical tasks, projects, and other work completed throughout the programme. The repository will continue to grow as I progress through the 24-week programme.

## Repository Structure

### Week-01 — Orientation & Computational Thinking
Foundations of Data Science and computational thinking.

Topics include:
- What Data Science is
- Data Science roles and lifecycle
- Computational thinking
- Problem decomposition
- Algorithms and pseudocode
- Python, Jupyter Notebook and VS Code setup
- Introduction to Python

### Week-02 — Systems Thinking, Git Practice & First Python Syntax
Building an understanding of how programs work while developing basic Python and Git skills.

Topics include:
- Input → Process → Output (IPO)
- Flowcharts
- How programs run
- Python interpreters
- Variables and memory
- Basic Python syntax
- `print()` and comments
- Running Python scripts
- Git branching and commits
- `.gitignore`
- README writing
- Debugging and reading errors
- First small Python project

### Week-03 — Variables, Data Types, Operators & Strings
Building a stronger foundation in Python programming.

Topics include:
- Variables
- Core data types
- Integers, floats, strings and booleans
- Arithmetic, comparison and logical operators
- Strings and string methods
- String formatting
- Type conversion
- User input
- Simple command-line programs
- Building a text-based calculator

### Week-04 — Conditionals & Loops
Learning how to control the flow of Python programs.

Topics include:
- `if`, `elif` and `else`
- Boolean logic
- Nested conditionals
- `while` loops
- `for` loops
- `range()`
- `break` and `continue`
- Nested loops
- FizzBuzz
- Number-guessing game

## Progress

This repository is a work in progress and will be updated throughout the 24-week Data Science programme.
