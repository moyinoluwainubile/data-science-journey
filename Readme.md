# Data Science Journey

This repository documents my 24-week journey of learning Data Science from the ground up.

It contains my learning exercises, Python scripts, Jupyter notebooks, practical tasks, projects, and other work completed throughout the programme. The repository will continue to grow as I progress through the 24-week programme.

## **Repository Structure**

### **Week-01 — Orientation & Computational Thinking**

Foundations of Data Science and computational thinking.

**Topics include:**
- What Data Science is
- Data Science roles and lifecycle
- Computational thinking
- Problem decomposition
- Algorithms and pseudocode
- Python, Jupyter Notebook and VS Code setup
- Introduction to Python

### **Week-02 — Systems Thinking, Git Practice & First Python Syntax**

Building an understanding of how programs work while developing basic Python and Git skills.

**Topics include:**
- Input → Process → Output (IPO)
- Flowcharts
- How programs run
- Python interpreters
- Variables and memory
- Basic Python syntax
- `print()` and comments
- Running Python scripts
- Git branching and commits
- `.gitignore`
- README writing
- Debugging and reading errors
- First small Python project

### **Week-03 — Variables, Data Types, Operators & Strings**

Building a stronger foundation in Python programming.

**Topics include:**
- Variables
- Core data types
- Integers, floats, strings and booleans
- Arithmetic, comparison and logical operators
- Strings and string methods
- String formatting
- Type conversion
- User input
- Simple command-line programs
- Building a text-based calculator

### **Week-04 — Conditionals & Loops**

Learning how to control the flow of Python programs.

**Topics include:**
- `if`, `elif` and `else`
- Boolean logic
- Nested conditionals
- `while` loops
- `for` loops
- `range()`
- `break` and `continue`
- Nested loops
- FizzBuzz
- Number-guessing game

### **Week-05: Core Python Data Structures**

Exploring lists, tuples, dictionaries, sets, indexing, slicing, and data structure methods. Applying these concepts to organise, access, and manipulate data through practical exercises and a CLI Inventory Tracker project.

**Topics include:**
- Lists
- Tuples
- Dictionaries
- Sets
- Indexing and slicing
- Data structure methods
- Iterating through collections
- Nested dictionaries
- Inventory Tracker project

### **Week-06: Functions, Files, CSV/JSON & Exceptions**

Learning to write reusable functions, understand variable scope and function arguments, read and write files, work with CSV and JSON data, and handle errors using exception handling. Applying these skills to build a CLI Personal Expense Logger with data persistence and input validation.

**Topics include:**
- Defining and calling functions
- Parameters and arguments
- Return values
- Variable scope
- Code reusability
- Reading and writing files
- CSV and JSON
- Exception handling
- Input validation
- Personal Expense Tracker project

### **Week-07: Comprehensions, Modules, OOP & Python Capstone**

Learning list and dictionary comprehensions, Python modules, package management with `pip`, virtual environments, and the fundamentals of object-oriented programming (OOP), including classes, objects, attributes, and methods. Applying these concepts in a practical Python capstone project to strengthen programming skills and prepare for more advanced data science work.

**Topics include:**
- List and dictionary comprehensions
- Python modules and imports
- Packages and `pip`
- Virtual environments
- Classes and objects
- Attributes and methods
- Object-oriented programming fundamentals
- Code organisation and reusability
- Python capstone project
