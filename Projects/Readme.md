# Data Science Journey — Projects

## **About This Folder**

This folder contains the major projects I will develop throughout my 24-week Data Science Foundation & Professional Development Programme.

These projects are designed to help me apply what I learn, work with real-world datasets, solve practical problems, and build a portfolio that demonstrates my growing technical skills.

Each major project will have its own folder, source files, and README documenting the problem, approach, findings, limitations, and skills demonstrated.

## **Project Development Standards**

Each major project will be documented to make the work understandable and verifiable.

**Where applicable, each project should include:**
- **README:** Problem, objectives, tools, approach, results, limitations, and instructions.
- **Source files:** Python scripts, SQL files, or other relevant code.
- **Data documentation:** Dataset source, structure, and relevant preparation steps.
- **Analysis and results:** Findings supported by the actual work.
- **Visualisations:** Charts or other outputs where relevant.
- **Reflection:** Lessons learned, challenges, limitations, and potential improvements.

Not every project will require every item. Documentation will reflect the project's actual requirements.

## **Progress Tracking**

Projects will be updated as I progress through the programme.

- **Planned:** The project is specified in the programme but work has not started.
- **In Progress:** Development or analysis is underway.
- **Completed:** The project meets its intended requirements and has been reviewed.
- **Published:** The completed project and its documentation are available on GitHub.

Project status will be updated based on actual progress, not merely because a project has been scheduled.
